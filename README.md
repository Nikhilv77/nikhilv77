## What I'm building

### [Trailgrad](https://trailgrad.com)
An end-to-end interview preparation platform for software engineers: guided practice in 5 domains,
voice and text mock interviews across 5 tracks, resume feedback, peer help, and a scored report
after every session.

- An AI interviewer that adapts to each candidate's role, experience, and resume, and follows up
  on their earlier answers
- A shared coding editor (Monaco, Yjs, LiveKit) that runs code in 5 languages inside isolated
  Judge0 and Vercel sandboxes
- Latency-aware AI routing: Gemini Live for voice, Groq for next-step decisions, Gemini Flash for
  grading, with automatic failover
- Safe concurrent state across serverless instances using PostgreSQL optimistic locking, Redis
  leases, and idempotency keys

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Redis` `Gemini` `Groq` `LiveKit` `Vercel`
